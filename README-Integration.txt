Plateau Publishing Co. — Digital & Services Add-On (Repo-Ready)

This package mirrors your GitHub repo structure. Drop these into the root of your site:
- /digital/           (lead-generation microsite: index, services, pricing, contact, assets)
- /services/          (category pages for Branding, Sponsorships, Digital Campaigns, Online Listings, Reviews & Reputation, Websites & SEO, PPC/Search)
- nav-snippet.html    (drop-in <nav> block to replace your current nav)

Quick Install
1) Copy the 'digital' and 'services' folders into the root of your repo.
2) Open your homepage (index.html) and replace the existing <nav>...</nav> with the contents of nav-snippet.html.
3) Optional: Add a hero CTA linking to /digital/pricing.html (e.g., "See Digital Packages").
4) Commit & push:
   git pull
   git add digital services nav-snippet.html
   git commit -m "Add /digital microsite + service pages + new top navigation"
   git push

What’s Included
- Lead-gen first: PPC/Search campaigns, Meta Lead Ads, Display retargeting, Landing pages, Conversion tracking (GA4/Tag Manager).
